Bot de Promoções Shopee

Cole o link do produto. Nome e preços vêm da Shopee e a mensagem fica pronta para o WhatsApp.

Conexão com a Shopee

As credenciais ficam guardadas no servidor e nunca voltam para o navegador. Você encontra o AppID e o Secret na área de API do painel de afiliados da Shopee.

Nova promoção

O preço "De" é calculado a partir do desconto informado pela Shopee. Confira e ajuste se precisar.

Prévia da mensagem

Cole um link para ver a mensagem.

No celular, a foto e o texto vão juntos para o WhatsApp e você escolhe o grupo. No computador, a foto é baixada e o texto é copiado para você anexar.

Fila de promoções

    "Enviar todas de uma vez" junta as promoções numa única mensagem, separadas por uma linha. O WhatsApp não permite mandar várias mensagens separadas com um só toque.
